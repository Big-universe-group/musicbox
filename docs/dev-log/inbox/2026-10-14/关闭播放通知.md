# 关闭播放通知

- 日期：2026-10-14
- 类型：问答 | 实现
- 分支 / 提交：master `b1730f0`（本次未提交；仅改本地配置 + .gitignore）

## 问题

关闭 my-musicbox 播放时弹出的播放通知。

## 结论 / 回答

1. 播放通知由 `NEMbox/player.py` 的 `Player.notify_playing()` 触发（`replay()` 里调用），switch song 时经 `NEMbox/utils.py:notify()` 走系统通知：
	+ macOS → `/usr/bin/osascript -e 'display notification ...'`
	+ Linux → `/usr/bin/notify-send -h int:transient:1`
2. 开关是配置项 `notifier`（默认 `true`），从 `~/.netease-musicbox/config.json` 读取（`Constant.config_path`，认 `XDG_CONFIG_HOME`）
3. 该 fork 只提供 `musicbox config get/list`，**没有** `config set`，也没有 TUI 配置菜单 → 只能手改 `config.json`
4. 生效条件：`Config` 是 Singleton，进程启动时读一次 → 改完要重启 TUI / `musicbox daemon stop && musicbox play ...`

## 改动

- `~/.netease-musicbox/config.json`：`notifier.value` `true` → `false`（`default` 保持 `true`，配置重新生成时会回到默认开）
- `.gitignore`：`docs/` → `docs/*` + `!docs/dev-log/`、`!docs/dev-log/**`（忽略目录本身则无法再放行子路径）
- `docs/dev-log/README.md`、`docs/dev-log/inbox/2026-10-14/`：本目录，首次建立

### 验证

`uv run musicbox config get notifier --json` → `{"ok": true, "data": {"notifier": false}}`；再用隔离 `XDG_CONFIG_HOME`（拷贝改后配置）跑临时脚本驱动真实 `Player(ui=NullUi()).notify_playing()`：`notifier=false` 时 `notify()` 调用 0 次，内存里翻成 `true` 后调用 1 次（`正在播放: t\na-b`）。

## 对需求的影响

新增：playback 通知默认关闭于本机配置（`default` 未改，仓库默认行为不变）。
